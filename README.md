# Novisteps-ClimbMode

**Novisteps-ClimbMode** は、競技プログラミングの非公式学習管理サイト「[AtCoder NoviSteps](https://atcoder-novisteps.vercel.app/)」をもとにした、あなたの適正レベルに合わせて自動で出題難易度が変動するChrome拡張機能（トレーニングツール）です。

解けた喜びと伸びる楽しさを最大化するためにデザインされた、エンドレスなマラソン形式の学習モードを提供します。

---

## ✨ 主な機能

* **🧗‍♀️ 難易度（グレード）の自動昇降**
  設定した初期グレードからスタートし、問題に対して「AC」を記録すれば次の問題は1段階難しく（+1 グレード）、「解説AC」などを記録すれば1段階易しく（-1 グレード）なります。あなたの実力ジャストのレベルをさまよい続けながら特訓が可能です。

* **🎯 1問集中UI（自動ハイライトと不要要素の非表示）**
  指定のグレードの中から「まだこのセッション解いていない問題」をランダムに自動で1問選び出します。指定された問題以外の行は全て自動で非表示にされるため、次に取り組むべき問題にだけ完全に集中できます。

* **⚡ シームレスな画面連動**
  拡張機能のポップアップだけでなく、Novistepsの画面上で直接「AC」「解説AC」などのボタンを押すだけで、そのまま結果が記録されて次の問題へと画面が自動遷移します。

* **📊 美しいリザルト画像とX(Twitter)へのシェア機能**
  セッションを終了すると、挑戦した問題名、難易度（グレード）、結果（AC / 解説AC）の履歴や推移などを可視化した美しいダッシュボードが新しいタブに生成されます。生成された画像は直接PNGでダウンロードできるほか、クリップボードに自動コピーしてX(Twitter)へ直接シェアできるボタンも完備しています。

## 🛠️ インストール（導入）手順

本拡張機能はChromeウェブストアを経由せず、デベロッパーモードから直接ブラウザに取り込んで使用します（ローカルインストール）。

1. このリポジトリのZIPファイルを右上の `Code` > `Download ZIP` からダウンロードし、任意のフォルダに解凍（展開）します。
2. Google Chrome を開き、URLバーに `chrome://extensions/` と入力して拡張機能の管理画面を開きます。
3. 画面の右上にある **「デベロッパー モード」** のトグルスイッチを**オン**にします。
4. 左上に新しく表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 手順1で解凍したフォルダ（`manifest.json` が含まれているフォルダ）を選択します。
6. Chromeの右上の拡張機能ピースアイコン（🧩）を押し、「Novisteps-ClimbMode」をピン留めしておくと便利です。

## 🎮 使い方

1. [AtCoder NoviSteps](https://atcoder-novisteps.vercel.app/) の **「一覧表」タブ内の「グレード別」** ページを開きます。
2. Chrome右上の拡張機能アイコンから「Novisteps-ClimbMode」のポップアップを開きます。
3. プルダウンから **「初期グレード」** を選び、**「セッション開始」** をクリックします。
4. 画面上の問題リストが自動で開き、ランダムにターゲット問題が1問だけ提示（ハイライト）されます。
5. 問題リンクをクリックしてAtCoderで問題を解きます。
6. 問題が解き終わったら（または諦めたら）、Novistepsの画面上でターゲット問題の右にある **「AC」** または **「解説AC」** などの回答ステータスを選択します。
7. 【**自動遷移**】拡張機能がステータスの変更を検知し、裏側で結果を記録、成績に応じて自動的に次のグレード・問題へとジャンプします。
8. 任意のタイミングでポップアップから **「セッション終了」** を押すと、全記録がまとめられたリザルト画像が出力されます！

## ⚠️ 注意事項・既知の制限

* この拡張機能はAtCoderおよびAtCoder NoviStepsの非公式ツールです。
* 対象ページは `https://atcoder-novisteps.vercel.app/*` 内の機能に依存しています。本体のサイトデザインやSvelteの構造が大きく変更された場合、正常に動作しなくなる可能性があります。
* 必ずNovisteps側のUIを通してステータスを更新してください。「挑戦中」「未挑戦」のテキストが「AC」などの画像に変わる（DOM変化）タイミングをトリガーに動作します。
